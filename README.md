# SURGICISS - Sterile Instrument Systems

![Logo](public/logo.png)

**Live Website:** https://paabazaa.github.io/surgiciss-clone-master/

A modern, responsive clone of SURGICISS official website for sterile surgical instrument systems.

### 🚀 Features
- Fully responsive design (mobile + desktop)
- Product catalog with dynamic routing
- Software showcase
- Instrument Count Sheet Holders
- Contact page
- SEO friendly + Fast Vite build

### 🛠️ Tech Stack
- React + TypeScript
- TanStack Router
- Tailwind CSS
- Vite
- Deployed on GitHub Pages

### 📦 Setup Locally

```bash
# Clone repo
git clone https://github.com/paabazaa/surgiciss-clone-master.git

# Install
npm install

# Run dev
npm run dev

# Build
npm run build
